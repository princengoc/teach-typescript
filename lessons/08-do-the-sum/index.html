Lesson 8: do the sum yourself

Until now you told the robot each move by hand. That does not scale: a lane a hundred squares long would need a hundred lines. This lesson you write a rule once, and a loop runs it at every square.

Part 1 — the rule

A rule is a function that gives back true or false. This one paints the lane's back half: it takes a square's number i and the lane's length, and answers one comparison — is i at least halfway along? 

function backHalf(i: number, len: number): boolean {
  return i >= len / 2;   // true when i is at least halfway
}

: boolean promises the answer is a yes or no. >= means "at least"; / divides. By itself the rule paints nothing — it only answers questions. Something has to ask it, once for every square.

Part 2 — the loop that runs the rule

The loop counts i up the lane. At each square it does three things: ask the rule, paint when the answer is yes, then step on. 

for (let i = 0; i < room.len; i += 1) {
  if (backHalf(i, room.len)) paint();   // ask the rule; paint on yes
  next();                               // step to the next square
}

Read it as those three jobs. for visits every square, from 0 to the last. if (backHalf(...)) paint() asks the rule about this square and paints only when it says yes. next() moves on. Press the button and watch one square at a time: the question, the answer, the paint.

Three rungs wait, each the same shape: write a rule, then a loop that runs it. Go build.
