Lesson 10: the list

Until now a room handed you one number at a time. This room hands you a whole list of them, and the list draws the picture.

Part 1 — a list of numbers

room.bars is — numbers, in order, under one name. Its type is number[]: a list of numbers. Each number is one bar of a chart, and a bar is a row that many squares long.

for...of walks it. Think of it as a const that gets a new value every turn: first n is the first number, then the next, until the list runs out. One number, one bar. 

for (const n of room.bars) {
  paintCells(n);
  nextRow();
}
