Lesson 7: how far?

Every move so far did something to the room and handed nothing back. This lesson, a function works out a number and gives it back, so the rest of your code can spend it.

A function that gives a number back

The robot faces a wall it cannot see the distance to. It feels its way, counting: the last square is 1, and every square before it is 1 more than the rest. The word return hands the count back. 

function measureGap(): number {
  if (robot.wallAhead()) return 1;   // last square: just 1
  robot.walk(1);
  return 1 + measureGap();           // me, plus the rest
}

const gap = measureGap();            // keep the number in a name
paintCells(gap);                     // spend it

: number is a promise: this function hands back a number. Watch the robot walk to a wall three squares away, counting one for each square. The count it reaches is the number it returns.

Why measure, not guess

The room picks the distance, not you. A guess with the number typed in fits the room you typed it for and no other. Here is a guess of 3 run in a gap-3 room and a gap-5 room.
