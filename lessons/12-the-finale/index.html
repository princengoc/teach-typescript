Lesson 12: the finale

Nothing new today. Everything you have written comes out at once, and it comes out as one walk with one rule in it.

Part 1 — one walk

A box is room.width squares across and room.height rows down. The walk goes over every square of it: a loop across, inside a loop down. 

for (let y = 0; y < room.height; y += 1) {
  for (let x = 0; x < room.width; x += 1) {
    if (rule(x, y, room)) {
      paint();
    }
    next();
  }
  nextRow();
}

Every square gets asked about. Every square gets stepped over. Only the yeses get painted. Change the rule and the same walk draws a different picture — that is the whole lesson.
