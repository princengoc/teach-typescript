Lesson 9: the grid

A box is rows, stacked. You can already paint one row. This lesson you put that whole loop inside another loop, and the second loop runs it once for every row.

Part 1 — one row

Here is the row loop you have written before. It paints a square, steps on, and stops at the end of the row. One new move waits at the foot: nextRow() carries the robot back to the first square of the row below. 

for (let x = 0; x < room.width; x += 1) {
  paint();
  next();
}
nextRow();

Part 2 — a loop of rows

Now wrap it. The outer loop counts y, one turn per row. Everything indented inside it — the whole row loop — runs again from the top each turn. 

for (let y = 0; y < room.height; y += 1) {
  for (let x = 0; x < room.width; x += 1) {
    paint();
    next();
  }
  nextRow();
}

Two counters, ticking at different speeds. y ticks times, once per row. x ticks times inside every one of those, once per square. Press the button and watch which one moves.

Three rungs wait, each a box walked by two loops. Go build.

The ladder

src/exercise.ts is open on the left. Fill it in, top to bottom. Rung 1 hands you the row; write the loop around it. Rung 2 you write both loops and the rule. Rung 3 the inner loop stops at a number your own function works out. Save and this panel marks every rung in every box.

Well done! A box, a checkerboard and a staircase, all from two loops.

Same two loops every time. The box painted at every square, the checkerboard asked a rule that reads both counters, and the staircase stopped its inner loop at a number worked out for that row.
